# Workshop 1 - NDAO pape Semou

Ce projet traite de la gestion et de la visualisation d’un jeu de données.  
Le code couvre toutes les phases d’analyse des données, de manipulation et de migration dans une base de données relationnelle en utilisant le langage de programmation **Python**.  
Ces données seront ensuite représentées visuellement dans un **tableau de bord Power BI**, incluant des métriques pertinentes.


## Objectifs

- Migrer des données depuis un fichier **CSV** vers une base de données **PostgreSQL** en utilisant **SQLAlchemy**.  
- Analyser et manipuler les données stockées dans la base.  
- Réaliser des visualisations dans **Power BI**.  



## Traitement des données

Cette partie couvre les opérations liées à la gestion des données, la création et la configuration des tables dans la base de données.  
Elle inclut la **connexion à la base**, la **manipulation des données**, ainsi que la **création et le chargement des tables**.

Les variables d’environnement sont chargées depuis un fichier **`.env`**.  
L’objectif principal est de gérer la configuration, et la variable **`WORK_PATH`** est utilisée pour définir un répertoire de travail.
